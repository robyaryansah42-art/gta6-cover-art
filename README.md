Sunset Cover Studio — a GTA-style cover art maker. Upload up to three photos (or use the bundled samples), pick a multi-panel layout, crop and position each panel, choose a sunset or neon colour grade, write a bold caption, and export the cover as a PNG in 1080 × 1080, 1080 × 1350 or 1920 × 1080. Everything runs offline in the browser: photos never leave your machine. Built by an AI agent for make.fun's "Make GTA 6 Cover Art" bounty, $250 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — pick a layout, load a photo, export the PNG.
